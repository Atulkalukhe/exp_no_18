Why does each bit have half the weight?

At each ladder junction, the network to the right is equivalent to 2R. The vertical 2R branch and continuing path divide the voltage by two, so successive bit weights are 1/2, 1/4, 1/8, and 1/16.

CONCEPTS & CHECKPOINTS

Learn by doing

Digital to analog

A DAC maps a discrete binary code to a proportional voltage. Digital inputs have two logic states; analog voltage varies continuously.

R and 2R ladder

Only two resistor values are used: R = 1 kΩ and 2R = 2 kΩ. The repeating divider gives binary weighted currents.

MSB and LSB

D3 is the MSB (1/2 VREF); D0 is the LSB (1/16 VREF). Four bits provide 16 codes.

Resolution & op amp

Ideal LSB step is VREF/16 = 0.3125 V at 5 V. The 741 converts weighted current to an inverted voltage.

Quick quiz

741 offset-null adjustment

In a physical lab, set all inputs to zero and adjust the 10 kΩ potentiometer connected to pins 1 and 5 until the output is near 0 V. This virtual control illustrates the trim concept; it does not model IC pin-level behavior.

Practical questions

1. Define resolution of DAC.

The smallest change in analog output caused by a one-code increment; here the ideal LSB step is VREF/16.

2. Purpose of op amp?

It holds the summing node near virtual ground and converts the ladder's weighted current into an output voltage.

3. How to null input offset?

With zero input code and a sensitive output voltmeter connected, adjust the offset-null potentiometer across pins 1 and 5 for an output as close to zero as practical.

4. Effect of number of input bits?

More bits increase the number of levels and improve resolution; for N bits there are 2ᴺ codes.
